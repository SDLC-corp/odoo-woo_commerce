Activation

Your activation journey: purchase to live sync.

Five phases over the first week. Most customers reach live operation by Day 5.

Day 0

Phase 1 - Purchase & Download

Complete checkout on Odoo App Store. Module download is available immediately. License key emailed to your registered address. Time: ~5 minutes.

Day 1

Phase 2 - Installation & Connection

Upload module ZIP into Odoo Apps. Install in one click. Generate WooCommerce REST API keys (Read+Write). Enter URL + Consumer Key + Consumer Secret. Test connection — green confirmation. Time: ~30 minutes.

Day 2

Phase 3 - Configuration & Mapping

Map warehouses, pricelists, tax classes, and order status flow. Enable webhook subscription. Configure cron schedules. Customize field mappings if needed. Time: 2-4 hours (or covered by 10 hours of free expert help).

Day 3

Phase 4 - Initial Bulk Import

Run guided import wizard: existing WooCommerce products, customers, and historical orders pull into Odoo. SKU matching prevents duplicates. Validate sample records before approving full import. Time: 1-2 hours for ~10,000 SKUs.

Day 5

Phase 5 - Live Sync Activated

Webhooks subscribed and active. Real-time sync triggers on every WooCommerce event. Monitor sync logs and retry queue dashboards. Confirm 24-hour clean run. You are live.

Step-by-step setup

Installation in 6 steps.

Most stores are syncing live data within 60 minutes from install.

1

Install the module

Download from Odoo Apps Marketplace. Upload the .zip or install directly from your database in Apps → Update Apps List.

2

Generate WooCommerce API keys

WordPress Admin → WooCommerce → Settings → Advanced → REST API → Add Key. Set Read/Write permissions.

3

Connect your store

Odoo → WooCommerce → Stores → New Store. Enter site URL, Consumer Key, Consumer Secret. Click "Test Connection".

4

Configure sync rules

Select data to sync, map warehouses and pricelists, set cron intervals, and enable webhook registration.

5

Run initial import

Import existing WooCommerce products and customers into Odoo in one click. Match by SKU to avoid duplicates.

6

Monitor sync logs

Go to WooCommerce → Sync Logs to review all events. Failed records appear in the Retry Queue.

Version: 16.0, 17.0, or 18.0 (CE or EE)

FAQs

Frequently asked questions.

Everything you should know before installing.

What is the WooCommerce Odoo Connector?

A native Odoo module that creates a two-way data bridge between your WooCommerce store and Odoo. Products, orders, customers, inventory, and pricing sync automatically — eliminating manual data entry.

Does it work with Odoo Community Edition?

Yes. Compatible with both Odoo Community (CE) and Enterprise (EE) on versions 16, 17, and 18. No Enterprise-only features are required.

Is this a one-time payment or subscription?

One-time payment of $9.99. No recurring fees, no annual renewal. You receive lifetime access to the version purchased plus free minor updates.

Can I connect multiple WooCommerce stores?

Yes. The connector supports unlimited WooCommerce stores connected to a single Odoo database, each with independent configuration for warehouses, pricelists, and sync rules.

How long does initial setup take?

Most installations are live within 30-60 minutes. Generate API keys in WooCommerce, enter them in Odoo, run the initial import, and you're syncing live data.

What happens if a sync fails?

Failed records enter a structured retry queue with full error details and payload visible in Odoo. You can retry manually or configure automatic retry intervals. Nothing is silently dropped.

Can the connector be customised for our workflow?

Yes. SDLC Corp offers professional services for custom sync rules, field mapping, third-party integrations, and enterprise deployment. Contact us at support@sdlccorp.com.

Do you offer a refund if it doesn't work?

Yes. We offer a full 30-day money-back guarantee. If you encounter a compatibility issue we cannot resolve, contact us for a refund — no friction, no questions.
