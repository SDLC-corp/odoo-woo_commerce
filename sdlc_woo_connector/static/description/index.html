0

Phase 1 - Purchase & Download

Complete checkout on Odoo App Store. Module download is available immediately. License key emailed to your registered address. Time: ~5 minutes.

1

Phase 2 - Installation & Connection

Upload module ZIP into Odoo Apps. Install in one click. Generate WooCommerce REST API keys, enter URL, Consumer Key, and Consumer Secret. Test connection for green confirmation. Time: ~30 minutes.

FAQs

Everything you should know before installing.

Short answers for buyers comparing Odoo WooCommerce connectors.

What is the WooCommerce Odoo Connector?

A native Odoo module that creates a two-way data bridge between WooCommerce and Odoo for products, orders, customers, inventory, and pricing.

Does it work with Odoo Community Edition?

Yes. It supports both Odoo Community and Enterprise editions for Odoo 16, 17, and 18.

Is this a one-time payment?

Yes. The listing is positioned as a $9.99 one-time purchase with no recurring connector subscription.

Can I connect multiple stores?

Yes. You can connect multiple WooCommerce stores to a single Odoo database with independent rules.

How long does setup take?

Basic installation can be completed quickly after API keys are generated. More complex mapping depends on catalog, taxes, and workflows.

What happens if a sync fails?

Failed records enter a retry queue with error details and payload visibility so your team can fix and retry them.
