DATA ENTITY WOOCOMMERCE → ODOO ODOO → WOOCOMMERCE TRIGGERED BY
Products & variants Bulk & single import, SKU matching Product updates pushed back Webhook + cron + manual
Categories & tags Created automatically on import Category push back Webhook + cron + manual
Orders & order lines Yes, as a full Odoo sale order Order status updates Webhook + cron + manual
Customers Direct import + created from order billing Contact changes pushed back Webhook + cron + manual
Inventory & stock status Stock levels & in/out-of-stock state Quantity & status via product push Cron + manual
Coupons Import with limits & expiry Export back to the store Webhook + cron + manual
Custom fields Mapped, including nested keys Mapped, core fields protected Applied on every sync

Because every record becomes a standard Odoo object, your existing chart of accounts, taxes and warehouses apply automatically. There is no parallel ledger to reconcile.

FAQs

Questions buyers ask us most.

Don't see yours? Email us at support@sdlccorp.com and we'll get back same business day.

Which Odoo versions are supported?

Odoo 17, 18 and 19, in both Community and Enterprise editions. It runs on self-hosted Odoo, on Odoo.sh, and on Odoo Online (SaaS) where custom modules are permitted on your plan. The connector is tested against fresh installs and common module combinations before each release.

Which WooCommerce versions does it work with?

WooCommerce 5.x and above, on WordPress 5.6+. The integration uses the standard WooCommerce REST API, so no custom WordPress plugins or theme modifications are required on your store.

Is the sync real-time, or scheduled?

Both. Orders and inventory sync via WooCommerce webhooks (near-instant). A cron-based fallback runs on a schedule you control, so any record missed by a webhook is reconciled automatically. You can also trigger a manual full sync from the dashboard.

Can I connect multiple WooCommerce stores to one Odoo?

Yes. Add as many stores as you need. Each one keeps its own catalog, customers, orders, and currency settings inside Odoo, while sharing your single Odoo backend for fulfillment, accounting, and reporting.

What happens if a sync fails?

Failures are logged in the Sync Reports view with full error context: the request payload, the response, and a stack trace if applicable. Most can be re-triggered with a single click, and the dashboard updates in real time so your team can see and clear any failed record.

Orders not syncing, or a WooCommerce webhook not working?

WooCommerce Odoo inventory sync issues and stalled orders almost always come down to one of three things: the webhook was never registered on the store, the HMAC-SHA256 signature is failing because the secret no longer matches, or the store is unreachable. The webhook log shows which of the three it is, and the connection health check flags an unreachable store before your customers notice. The cron fallback then re-imports anything the webhook missed.

Does it sync WooCommerce coupons and discounts?

Yes, in both directions, including discount type, usage limits and expiry dates. Coupon sync is one of the most commonly omitted features in WooCommerce Odoo integrations, so it is worth checking against any connector you are comparing us with.

Is there a free Odoo WooCommerce connector?

There are open-source options, and they are a reasonable choice if you have Odoo developers on staff. You will be configuring several modules and maintaining them yourself through every version upgrade. This connector is a one-time purchase with implementation included, which is usually the cheaper path once someone has to own the integration long term.

How do I migrate WooCommerce to Odoo, or import existing data?

Run a bulk import of products, categories, customers, orders and coupons to establish the baseline, then switch on webhooks for ongoing sync. You can also import by ID or by date range if you would rather migrate history across in stages. Setup guide and documentation are linked at the top of this page, and the included implementation hours cover the first end-to-end run.
